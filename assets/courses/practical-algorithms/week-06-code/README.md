# Week 6 code / 6주차 코드

Python 3.11+; standard library only. Extract the archive and run in `code`:

```text
python demo_11.py
python demo_12.py
python verify.py
python verify.py --student
```

Implement `student_week_06.py` before using `--student`. Completed solutions are in `solutions.py`. The verifier compares small cases against independent exhaustive methods and checks large boundary inputs. Tests support debugging; the worked companion explains correctness.

Python 3.11 이상과 표준 라이브러리를 사용합니다. 압축을 푼 `code` 폴더에서 실행합니다. `--student`는 `student_week_06.py`를 구현한 뒤 사용합니다. 완성 풀이는 `solutions.py`에 분리되어 있습니다. 검사는 작은 입력의 완전 탐색 결과와 큰 경계 입력을 대조하며, 정당성은 읽기자료에서 설명합니다.

`acyclic_dfs_small` is an optional small-graph demonstration; use `course_order` / `can_finish` for long chains.

`acyclic_dfs_small`은 작은 그래프의 선택 예제입니다. 긴 연결 그래프는 `course_order` / `can_finish`로 처리합니다.

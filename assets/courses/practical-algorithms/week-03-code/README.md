# Week 3: Binary search and linked lists

Use Python 3.11 or later. Run `python verify.py` from this directory. Implement `student_week_03.py` independently, then use `python verify.py --student`. Completed implementations are in `solutions.py`.

The search functions assume the official nonempty input contracts. Linked-list functions reuse nodes; merging assumes separate acyclic lists. Adapt the names and signatures to the official LeetCode methods.

## 3주차: 이진 탐색과 연결 리스트

Python 3.11 이상에서 이 폴더의 `python verify.py`를 실행합니다. `student_week_03.py`에 직접 구현한 뒤 `python verify.py --student`로 확인합니다. 완성 풀이는 `solutions.py`에 있습니다.

탐색 함수는 공식 문제의 빈 입력이 아닌 조건을 따릅니다. 연결 리스트 함수는 노드를 재사용하며 병합할 두 리스트는 서로 겹치지 않고 사이클이 없어야 합니다. LeetCode에 제출할 때 공식 메서드 이름과 매개변수에 맞춥니다.
